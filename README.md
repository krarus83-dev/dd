# Маркет на React + Redux Toolkit

Демонстрационный магазин с 100 товарами: React, Redux Toolkit и React Redux. Корзина и язык хранятся в Redux (`src/store.js`), а также сохраняются в localStorage. Поиск, сортировка и открытие корзины — локальное состояние интерфейса React.

Язык меняет валюту: русский — рубли, узбекский — сумы, английский — доллары. Курсы для демонстрации: 1 USD = 90 RUB и 1 USD = 12 500 UZS; они не обновляются автоматически. Оплата и оформление заказа не подключены.

Готовая автономная версия: `dist/market-react.html`. Изображения и библиотеки включены в файл; подключение к интернету не требуется.

Для пересборки установите Node.js, выполните `npm install`, затем `npm run build`. Результат: `dist/market-react.html`. Компонент — `src/App.jsx`, Redux store и slices — `src/store.js`, стили — `src/style.css`, каталог — `src/products.json`.
